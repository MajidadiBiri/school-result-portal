# Majidadi - Student Result Portal
### 3MTT Capstone Project

## 📌 Problem Context
In Nigeria, accessing academic results often requires physical presence or slow manual systems. This portal solves this issue by providing a fast, lightweight, and accessible result verification system for students. Built specifically for **Majidadi**, it allows students to check their terminal academic results seamlessly online.

## ✨ MVP Features
- **Instant Result Verification:** Search student records using IDs from `STU101` to `STU115`.
- **Dynamic Grading System:** Automatically computes subject grades (A, B, C, D, F) and average performance score.
- **Lightweight Database:** SQLite backend storing student records, scores, classes, and genders.
- **Responsive UI:** Clean, modern interface designed in English with a built-in **Print Result Slip** feature.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js (REST API)
- **Database:** SQLite3
