# Majidadi - Student Result Portal

An official full-stack web application built for **Majidadi** to enable students to easily check their terminal academic results online using their unique Student ID.

## 🚀 Live Demo & Links

* **Deployed Web App:** [https://school-result-portal-qz7v.onrender.com](https://school-result-portal-qz7v.onrender.com)
* **GitHub Repository:** [https://github.com/MajidadiBiri/school-result-portal](https://github.com/MajidadiBiri/school-result-portal)

---

## ✨ Features

* **Instant Result Retrieval:** Search student records quickly using IDs from `STU101` to `STU115`.
* **Automated Grading System:** Calculates subject grades (A, B, C, D, F) and total average score dynamically.
* **Responsive UI:** Clean, modern, and mobile-friendly interface tailored for all devices.
* **Printable Result Slip:** Built-in print feature for downloading or printing result slips directly.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Backend:** Node.js, Express.js
* **Database:** SQLite3 (In-Memory Database)
* **Deployment:** Render
