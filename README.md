# 3MTT Capstone Project - School Result Portal

## Problem Context
In Nigeria, accessing academic results often requires physical presence or slow manual systems. This portal solves the issue by providing a fast, lightweight, and accessible result verification system for students.

## MVP Features
- Student Authentication via unique Student ID.
- Real-time Result Checking interface.
- Lightweight SQLite database for storing student records and scores.
- Express.js API backend.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (Fetch API)
- Backend: Node.js, Express.js
- Database: SQLite3

## How to Run Locally
1. Clone the repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Start the server: `node server.js`
4. Open `http://localhost:3000` in your browser.
